# Roadmap

## V1

- Mobile PWA shell
- Persistent mock SRS and working text drill
- Learned Items recent/category views
- Assessment and can-do curriculum
- Vapi prompt files and wrapper
- Airtable/Make schemas and webhook adapter

## V2

- Live Make webhooks and Airtable writes
- Vapi Web SDK and real voice sessions
- Database-backed learned items and assessment
- Protected webhook proxy before wider use

## V3

- Supabase option, authentication, improved scheduler
- Session analytics and progress dashboard

## V4

- Short stories with two-to-four comprehension questions
- Audio flashcards, kana visual modules, and streaks

## V5

- React Native/Expo app
- Native audio, offline review, and richer real-time voice UI
